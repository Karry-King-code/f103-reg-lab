## 2. 寄存器版工程和另两个仓库差在哪（本章核心知识点）

```
标准库版: main.c → SPL 函数(GPIO_Init) → 封装内部写寄存器 → 硬件
HAL  版: main.c → HAL 函数(HAL_GPIO_Init) → 封装(更厚) → 硬件
寄存器版: main.c → 直接写 GPIOC->CRH 等寄存器 → 硬件
```

本仓库 `User/main.c` 之外**没有任何外设驱动 .c**——对比：

| | 标准库 | HAL | 寄存器 |
|---|---|---|---|
| 外设驱动 .c 文件 | rcc/gpio/misc（按需加） | 全量 HAL（链接器裁剪） | **0 个** |
| 头文件体系 | stm32f10x.h + conf.h | stm32f1xx.h + hal_conf.h | **仅 stm32f10x.h** |
| 工程宏 | `USE_STDPERIPH_DRIVER,STM32F10X_MD` | `USE_HAL_DRIVER,STM32F103xB` | **只留 `STM32F10X_MD`** |
| 编译产物（空工程） | Code=852B | Code=1838B | Code=852B |

**知识点：没有库 ≠ 没有头文件。** `stm32f10x.h` 是 ST 官方 **CMSIS 设备头文件**，它不"干活"，只干一件事：**把芯片手册里的每个寄存器变成 C 结构体**。例如：

```c
#define PERIPH_BASE           0x40000000UL
#define APB2PERIPH_BASE       (PERIPH_BASE + 0x10000UL)
#define GPIOC_BASE            (APB2PERIPH_BASE + 0x1100UL)   /* GPIOC 在 0x40011000 */

typedef struct {
  __IO uint32_t CRL;    /* 偏移 0x00: 低 8 脚配置 */
  __IO uint32_t CRH;    /* 偏移 0x04: 高 8 脚配置 */
  __IO uint32_t IDR;    /* 偏移 0x08: 输入数据 */
  __IO uint32_t ODR;    /* 偏移 0x0C: 输出数据 */
  __IO uint32_t BSRR;   /* 偏移 0x10: 原子置位/复位 */
  __IO uint32_t BRR;    /* 偏移 0x14: 原子复位 */
  __IO uint32_t LCKR;   /* 偏移 0x18: 锁定 */
} GPIO_TypeDef;

#define GPIOC               ((GPIO_TypeDef *) GPIOC_BASE)
```

于是 `GPIOC->ODR = 0x2000;` 就是一条"往地址 0x4001100C 写 1"的 C 语句——**寄存器编程的本质：按芯片手册的地址和位定义读写内存**。这些结构体定义全部来自芯片手册的 memory map，不是我们编的，可以在 `stm32f10x.h` 里逐行核对（02 章点灯就带着核对一遍 GPIOC/RCC）。

**知识点：为什么 `__IO`？** `#define __IO volatile`。告诉编译器"这个地址的值随时会被硬件改变，禁止优化缓存它的读写"。没有 volatile，`while(GPIOA->IDR & 1)` 这种等待语句会被优化成死循环。

## 6. 上电到 main()（三仓库同一链路）

```
复位 → 0x08000000 向量表 → Reset_Handler
     → SystemInit()（HSI 8MHz 安全起跑）
     → __main（搬 RW/清 ZI）→ main()
```

三个仓库的启动链路完全相同（用的是同一份 ST 官方启动文件与 SystemInit）——**芯片不管你用什么库**，库只是 main() 之后的分叉。这也是三条线能"同一功能三实现"的根基。

# 02 · 点亮 LED（寄存器版，1 秒闪烁）✅ 已验收 2026-10-05

> 不用任何外设库函数，直接读写寄存器。这一章做完，你就知道标准库/HAL 那些函数背后"真正发生了什么"。

## 硬件事实（实测，与前两版一致）

| 目标 | 引脚 | 动作 |
|---|---|---|
| 绿灯 | PC13（低电平亮） | 引脚输出 0 → 亮 |
| 继电器 | PC14（本程序不碰，想咔哒就照样配 PC14） | 输出 0 → 吸合 |

## 步骤 6 · 开时钟：一个位的事

```c
RCC->APB2ENR |= RCC_APB2ENR_IOPCEN;
```

- `RCC->APB2ENR`：APB2 总线外设时钟使能寄存器，地址 0x40021018；
- `RCC_APB2ENR_IOPCEN` = `0x00000010`，就是 **bit4**（stm32f10x.h 里的位掩码宏，等价写 `1U<<4`）；
- `|=` 只点亮这一位，不碰别的位（直接 `=` 会把其他外设时钟全关掉——经典事故）。
- 这就是标准库 `RCC_APB2PeriphClockCmd()` 和 HAL `__HAL_RCC_GPIOC_CLK_ENABLE()` 的真身。

## 步骤 7 · 配引脚：CRH 每 4 位管一个脚

GPIOC 的配置分两个寄存器：**CRL 管 PC0~7，CRH 管 PC8~15**。每 4 位一格，格式：

```
[CNF1 CNF0 MODE1 MODE0]
  模式选择    速度/方向
```

PC13 是 13 号脚 → CRH 的第 (13-8)=5 格 → **CRH[23:20]**。
推挽输出 2MHz = CNF=00 + MODE=10 = `0b0010`。

```c
GPIOC->CRH = (GPIOC->CRH & 0xFF0FFFFFU) | 0x00200000U;
/*           └ 先清掉 PC13 那 4 位      └ 再填入 0010，其他脚不动 */
```

标准库 `GPIO_Init(GPIOC,&gpio)` 的内部，做的就是这一句。**⚠️ 引脚和位对不上是新手第一大坑**：PC13≠CRH[15:12]（那是 PC11），数格子：(13-8)×4=20，从 bit20 起。

## 步骤 8 · 控制输出：BSRR/BRR 原子操作

| 想做什么 | 写哪个寄存器 | 效果 |
|---|---|---|
| 输出高（灭） | `GPIOC->BSRR = GPIO_BSRR_BS13;` | bit13 写 1 → 输出置位 |
| 输出低（亮） | `GPIOC->BRR = GPIO_BRR_BR13;` | bit13 写 1 → 输出复位 |

**为什么不用 ODR 直接写**：`ODR ^= mask` 是"读-改-写"三步，中断若插进来改了同寄存器会被覆盖；BSRR/BRR 写 1 生效、写 0 无视，**单条指令原子完成**——这就是它们存在的原因。

## 步骤 9 · 完整代码（`User/main.c` 全文）

```c
#include "stm32f10x.h"

void delay_ms(uint32_t ms)                    /* SysTick 延时：内核外设，三种写法都得自己配 */
{
    uint32_t tick = SystemCoreClock / 8 / 1000;
    SysTick->LOAD = tick - 1;
    SysTick->VAL  = 0;
    SysTick->CTRL = SysTick_CTRL_ENABLE_Msk;
    while (ms--)
        while ((SysTick->CTRL & SysTick_CTRL_COUNTFLAG_Msk) == 0) { }
    SysTick->CTRL = 0;
}

int main(void)
{
    SystemCoreClockUpdate();                  /* 实测 72MHz（HSE 8M x PLL9） */

    RCC->APB2ENR |= RCC_APB2ENR_IOPCEN;       /* ① 开 GPIOC 时钟 */
    GPIOC->CRH = (GPIOC->CRH & 0xFF0FFFFFU) | 0x00200000U;  /* ② PC13 推挽输出 2MHz */
    GPIOC->BSRR = GPIO_BSRR_BS13;             /* ③ 上电先灭（输出高） */

    while (1)
    {
        GPIOC->BRR  = GPIO_BRR_BR13;          /* 低 -> 亮 */
        delay_ms(1000);
        GPIOC->BSRR = GPIO_BSRR_BS13;         /* 高 -> 灭 */
        delay_ms(1000);
    }
}
```

## 步骤 11 · 三条腿对比（三条腿齐了，这张表是本教程的纲）

| 动作 | 标准库 | HAL | 寄存器 |
|---|---|---|---|
| 开 GPIOC 时钟 | `RCC_APB2PeriphClockCmd(...)` | `__HAL_RCC_GPIOC_CLK_ENABLE()` | `RCC->APB2ENR \|= 1U<<4` |
| 配 PC13 推挽 | `GPIO_Init(GPIOC,&gpio)` | `HAL_GPIO_Init(GPIOC,&gpio)` | `GPIOC->CRH = (...) \| 0x2<<20` |
| 输出低（亮） | `GPIO_WriteBit(...,Bit_RESET)` | `HAL_GPIO_WritePin(...,RESET)` | `GPIOC->BRR = 1U<<13` |
| 毫秒延时 | 自己写 SysTick | `HAL_Delay()`（库代劳） | 自己写 SysTick（同一份） |
| Code 体积 | 2816B | 2476B | **1000B** |
| 可读性 | 函数名即语义 | 封装最厚 | 每行都是硬件真相 |

**一句话**：三种写法，一个硬件。标准库/HAL 是给寄存器操作"穿衣服"，寄存器是裸奔——衣服换来可读性和可移植性，裸奔换来体积和彻底理解。生产用 HAL，教学三条都要会。

## 知识卡 · "操控的是哪几位"是怎么知道的（三层证据）

**证据 1 · 头文件原文**（`Libraries/CMSIS/.../stm32f10x.h`，工程里就有）：

```c
#define RCC_APB2ENR_IOPCEN   ((uint32_t)0x00000010)  /* I/O port C clock enable */   // 0x10 = bit4
#define GPIO_BSRR_BS13       ((uint32_t)0x00002000)  /* Port x Set bit 13 */          // 0x2000 = 2^13 = bit13
#define GPIO_BRR_BR13        ((uint16_t)0x2000)      /* Port x Reset bit 13 */
```
宏的值本身就是答案：`0x10` 二进制是 `100`，就是 bit4；`0x2000` 是 2^13，就是 bit13。

**证据 2 · 参考手册 RM0008 中文版**（`4_硬件资料_芯片资料.1_STM32F103xx参考手册(中文参考).pdf`）：

| 内容 | 手册位置（PDF 页码） |
|---|---|
| RCC_APB2ENR 位表（IOPCEN 在 bit4） | 第 71 页 |
| GPIOx_CRH 位图（MODE13[1:0]=[21:20]，CNF13[1:0]=[23:22]；MODE=10 即"输出 2MHz"，CNF=00 即"通用推挽"） | 第 114 页 |
| GPIOx_BSRR 位表（低 16 位 BSy 置位，高 16 位 BRy 复位） | 第 115 页 |

**推导公式**（可自己算，不用背）：
- BSRR/BRR/ODR/IDR：**一位对应一个引脚，位号 = 引脚号**（PC13 → bit13）；
- CRH：管 PC8~15，每脚 4 位，PCn 起始位 = **(n-8)×4**（PC13 → (13-8)×4 = bit20 起，即 [23:20]）；
- 推挽输出 2MHz 的 4 位值：CNF=00 + MODE=10 → `[CNF1 CNF0 MODE1 MODE0]` = `0b0010` = 0x2。

**证据 3 · 实测（终极验证）**：烧上板绿灯按预期闪。位错一位灯都不会动。进阶验证：Keil 调试模式下挂起 CPU，能直接在 Watch 窗口看 `GPIOC->CRH` 的实时值——调试章节教你。

## 知识卡 2 · BSRR / BRR / ODR / IDR 四兄弟：怎么用、用哪几位

### 一张表认清

| 寄存器 | 全名 | 手册页 | 读写 | 人话 |
|---|---|---|---|---|
| ODR | 输出数据寄存器 | 114 页 | 读/写 | 我**想让**引脚是什么电平（我方意图） |
| IDR | 输入数据寄存器 | 114 页 | **只读** | 引脚**实际**是什么电平（硬件实况） |
| BSRR | 位设置/清除寄存器 | 115 页 | 只写 | 一条指令安全翻脚，置位/复位都能干 |
| BRR | 位清除寄存器 | 115 页 | 只写 | BSRR 的精简版，专管拉低 |

### 用哪几位：位号 = 引脚号

四个寄存器都是"一位管一个引脚"。PC13 的灯从头到尾只用 **bit13**：

```
0x00002000 = 0010 0000 0000 0000   <- 1 在第 13 位，其余写 0（BSRR/BRR 写 0 = 无视）
```

### 点灯的位级过程

```c
GPIOC->BRR  = GPIO_BRR_BR13;         // 写 0x2000：BRR bit13=1 -> PC13 清 0 -> 亮
GPIOC->BSRR = GPIO_BSRR_BS13;        // 写 0x2000：BSRR bit13=1 -> PC13 置 1 -> 灭
GPIOC->BSRR = GPIO_BSRR_BS13 << 16;  // 写 0x20000000：BSRR 高16位 bit13(=整32位bit29) -> 同样清 0 亮
```

BSRR 低 16 位管"输出高"(Set)，高 16 位管"输出低"(Reset)；还能一条指令同时亮 A 灭 B。

### ODR 的看家本领与代价

```c
GPIOC->ODR ^= GPIO_ODR_OD13;         // 一句话翻转（亮<->灭）
```

但 `^=` 是**读-改-写三步**，中间被中断插队改了同寄存器，写回会覆盖中断的修改（竞态）。BSRR/BRR 单条指令原子完成，无此窗口。

### 工程选用规矩

| 场景 | 用哪个 |
|---|---|
| 置位/复位（点亮/熄灭） | BSRR / BRR（本教程代码的选择） |
| 翻转（方波/呼吸灯） | 中断环境下慎用 `ODR ^= `，或读 IDR 后走 BSRR |
| 读引脚真实电平（04 章按键） | `GPIOC->IDR & (1U<<7)` 读 KEY1(PB7)——IDR 是实况，被外部拉低也能读出来 |
